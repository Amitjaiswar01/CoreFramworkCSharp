# View Image Comments in Visual Studio

Using the ImageComments Visual Studio plugin we have the possiblity of adding images to summary blocks to provide visual context.
Information about ImageComments can be found [here](https://marketplace.visualstudio.com/items?itemName=MsBishop.ImageComments)

1. Install [ImageComments.vsix](../../packages/).
2. Comments can now be added to summaries in Visual Studio.

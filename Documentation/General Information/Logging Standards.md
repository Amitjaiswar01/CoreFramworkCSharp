# Logging Standards
This document details the requirements for test logging.

Name of the individual running the test
Test summary
Update soft assert
Testing environment
Record activities/events for each relevant detail, including the beginning and end of activities, and the occurrence date and time
Expected and actual results when the test is passed
Three rerun for failed test
Clarity reason of failed test
E.g.unable to find this element on the screen
When bug found, use trail to track task and skip the test (need to prioritize to be fixed)
Commit hash for test automation
A link to the screenshot(take screenshot for failed test)
Manual layout verification
Catch handle exception(Object reference not set to an instance of an object)

# Logging Standards

This document details the requirements for test logging. Logging should include:

1. Class file name of the test that is running (which includes the Adaptavist ID e.g. T252).
2. Test environment information.
3. Record activities/events for each relevant detail, including the beginning and end of activities, and the occurrence date and time.
4. Expected and actual results when the test is passed.
5. A link to the screenshot (The framework takes a screenshot regardless if the test passes or fails).

If the test fails:

6. Catch handle exception (e.g. Object reference not set to an instance of an object).

# Lamps Plus Test Automation Utility Class Standards
This document details the code standards and preferences for development of utility class and functionality.  
Examples can be found:  
* https://bitbucket.lampsplus.com:8443/projects/LAMPS/repos/test-automation/browse/LampsPlus.AutomationFramework/Utilities 
* https://bitbucket.lampsplus.com:8443/projects/LAMPS/repos/test-automation/browse/Automation.Framework/Utilities

## General
- There should only be one Utilities folder per project.
- Do not use utils or abbreviations: spell out utilities.
- Group similar functionality whenever possible.
- Follow LampsPlus coding standards. These standards can be found in Confluence [here](https://confluence.lampsplus.com:8093/display/WDA/BED+Coding+Standards+-+C%23+and+TSQL).
